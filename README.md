## Информационно-аналитическая система (ИАС) розничных продаж

Данный проект представляет собой программный комплекс для автоматизации процессов загрузки, хранения и аналитической обработки данных о розничных продажах. Система разработана в рамках учебного проекта и реализует полный цикл работы с данными: от ETL-процесса до построения визуализированных отчетов.

### Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Junk04/pz3_mispias.git
   cd pz3_mispias```

2. Установите необходимые зависимости:
    ```pip install pandas numpy matplotlib seaborn```

3. Для запуска версии с графическим интерфейсом (GUI):

    ```python main.py```

    Для запуска консольной версии (CLI):
    
    ```python main.py --cli```
